# Property Reel Maker

Browser-based tool by **Think Through Technology** that turns property photos and details into a vertical (1080×1920) MP4 reel for Instagram Reels, YouTube Shorts and WhatsApp status.

**Live:** https://maheshkumar040795-afk.github.io/Property_Reel_Maker/

## Features
- Client branding presets (name, phone, logo, colours) saved in the browser
- Photo upload, reorder, captions; wide photos get a blurred background
- Auto-written voice script in English or Tamil, one line per scene
- Voice per scene: ElevenLabs (cloned voice), mic recording, or uploaded audio
- Scenes stay on screen as long as their voice line
- Built-in background music (auto-lowered under voice) or your own MP3
- Exports MP4 in the browser (WebCodecs + mp4-muxer) — no server, no cost

## Use
Open in **Chrome or Edge** (laptop or Android) → fill details → add photos → **Create MP4** → Download / Share.

The ElevenLabs API key is stored only in your browser (if "Remember" is ticked). Do not commit keys to this repo.
